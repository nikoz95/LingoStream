# LingoStream — Documentation Index

All project documentation lives in this folder. Start with `AGENTS.md` at the
repository root for the agent-facing quick guide.

| Doc | Use it when |
|---|---|
| [architecture.md](architecture.md) | You need project structure, layers, and boundaries |
| [features.md](features.md) | You need to know which files implement a feature |
| [api.md](api.md) | You are touching endpoints, data flow, or integrations |
| [conventions.md](conventions.md) | You are writing new code and unsure of style |
| [testing.md](testing.md) | You are running or adding tests |
| [deployment.md](deployment.md) | You are changing builds, Docker, or config |

> If a doc contradicts the code, **the code wins** — then fix the doc.
